# Vereinsring Urbar – öffentliche Vorschau

Vorschlag für einen gemeinsamen Internetauftritt des Vereinsrings und der Vereine in Urbar.

Die Seite ist ausdrücklich als öffentliche Vorschau gekennzeichnet. Vereinszugehörigkeiten, Termine, Texte und Kontaktdaten müssen vor einem offiziellen Start vom Vereinsring geprüft und freigegeben werden.

## Technik

Statische HTML-, CSS- und JavaScript-Dateien für GitHub Pages. Keine Cookies, keine Analyse und keine extern geladenen Schriftarten.

## Eigene Domain

Eine `CNAME`-Datei wird erst ergänzt, wenn die Domain tatsächlich registriert und die DNS-Zuordnung freigegeben ist. Bis dahin bleibt die GitHub-Pages-Vorschau erreichbar.
